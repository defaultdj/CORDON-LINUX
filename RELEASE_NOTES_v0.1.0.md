# CORDON-LINUX v0.1.0 — Порт лаунчера S.T.A.L.K.E.R. под Linux (OpenXRay)

Первый официальный выпуск **CORDON-LINUX** — менеджера профилей и модов S.T.A.L.K.E.R. для Linux, оптимизированного под движок **OpenXRay**.

---

### 🚀 Что нового в версии v0.1.0

1. **Linux-порт лаунчера CORDON:**
   * Полная поддержка CLI (`cordon`: 27 команд) и GUI (`cordon-gui`).
   * Адаптация под движок OpenXRay и нативные Linux-сборки.
   * Безопасное построение оверлея профиля через символические ссылки (`link`) и `fuse-overlayfs`.
   * Автоматическое подключение шейдеров движка (`gamedata/shaders`).

2. **Адаптация интерфейса под экраны 1024x768:**
   * Окно лаунчера 992x696 и выпадающие меню («Ещё ▾», «Открыть ▾») аккуратно помещаются на компактных экранах.
   * Восстановлены пункты «Настройки профиля», «Собрать» и «Проверить» в меню «Профиль ▾».

3. **Интеграция в системное меню приложений:**
   * Создан ярлык `cordon-linux.desktop`, помещённый исключительно в категорию **Игры** (`Categories=Game;`).
   * Установщик `install.sh` валидирует ярлык и обновляет кэши меню (`update-desktop-database`, `gtk-update-icon-cache`, `kbuildsycoca`).

4. **Проверка готовых сборок при добавлении модов:**
   * Добавлена проверка: если папка, добавляемая как «мод», содержит `fsgame.ltx`, `bin/` или `levels/`, лаунчер и предполётная проверка (`doctor`) предупреждают, что это готовая автономная сборка (standalone), а не обычный мод.

5. **Тестирование и автоматизация:**
   * 184 модульных теста (`pytest tests/cordon`).
   * Скрипт дымового тестирования `cordon-smoke-test.sh` (14/14 проверок без ошибок).
   * Автоматический CI/CD воркфлоу GitHub Actions на `ubuntu-latest`.

### 📦 Быстрая установка

#### Вариант 1: Установка через скрипт `install.sh` (рекомендуется)
```bash
git clone https://github.com/defaultdj/CORDON-LINUX.git
cd CORDON-LINUX
bash install.sh
cordon-gui
```

#### Вариант 2: Установка из Wheel-пакета (`.whl`)
```bash
pip install cordon_linux-0.1.0-py3-none-any.whl[gui]
cordon-gui
```

#### Вариант 3: Сборка Arch Linux (AUR / PKGBUILD)
```bash
cd packaging/arch
makepkg -si
```
